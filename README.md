# LaraPaper Home Assistant Add-on Repository

[![Add repository to HA](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fsiveryt%2Fhassio-larapaper)

## Add-ons in this repository

### LaraPaper

Self-hosted [TRMNL](https://usetrmnl.com) dashboard server powered by [LaraPaper](https://github.com/usetrmnl/larapaper).

## Installation

1. Navigate to **Settings > Add-ons > Add-on Store** in Home Assistant.
2. Click the menu (three dots) in the top-right and select **Repositories**.
3. Add this repository URL.
4. Find **LaraPaper** in the store and install it.
